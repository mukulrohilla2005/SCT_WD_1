# MOOVY 🎬

MOOVY is a fully responsive movie streaming website frontend inspired by modern OTT platforms.
It features a sleek UI, smooth animations, interactive FAQ section, trending movie carousel, responsive layouts, email validation, auto-scrolling sections, dynamic greetings, and multiple JavaScript-based interactive effects.

## Features

* Fully Responsive Design
* Interactive FAQ Section
* Email Validation
* Smooth Hover Animations
* Auto Scrolling Trending Movies
* Dynamic Greeting Message
* Scroll To Top Button
* Ripple Button Effects
* Background Image Changer
* Modern OTT Platform UI

## Technologies Used

* HTML5
* CSS3
* JavaScript
